This is a minecraft redstone circuit that implements [Simplified DES](https://www.math.umd.edu/~immortal/ClassNotes/simplifieddes.pdf) built by me and my friend [xiberxia](https://github.com/xiberxia/)


[dist.zip](./dist.zip) contains only the circuit
[dev.zip](./dev.zip) contains a development world

These circuits were built for minecraft version 26.2
